# Syrinx Working Rules

## Versioning

- Every implementation change must bump the Syrinx application version in
  `parrot/Resources/SyrinxApp/Info.plist`.
- Keep the current version and release-command examples in `README.md` aligned
  with the application version.

## Delivery

- Complete each implementation change on a feature branch, push the branch,
  and create a pull request before reporting the work as complete.
