# Research boundary

This repository is a new implementation. It does not copy application source,
assets, names, package identity, or history from reference projects.

- MacParakeet is reference evidence for native Swift, Core ML, and FluidAudio
  behavior. Its GPL-3.0 application source, assets, identity, and history are
  not implementation inputs.
- achetronic/parakeet is HTTP contract evidence only. Its Go application
  source, assets, identity, and history are not implementation inputs.
- FluidAudio is pinned as the native runtime dependency and is used only
  through its public ASR API.

The architecture plan at `private planning document`
defines the selected clean Swift product shape.
